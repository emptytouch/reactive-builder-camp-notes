## 关键概念（今天新学的）

- 订阅六参数：`chainId, contract, topic0, topic1, topic2, topic3`。`0` / `address(0)` / `REACTIVE_IGNORE` 分别表示链、合约、topic 位的通配。
- **只支持精确相等**；单个订阅内无 OR；至少一项具体；订阅存在节点里不在 storage 里。
- `unsubscribe()` 必须六项**完全一致**，否则静默失败——老订阅还在继续扣钱。
- `LogRecord`：`data` 只有**非 indexed** 参数；`opCode` = topic 数量；`blockHash` / `txHash` 是 `uint256` 不是 `bytes32`。
- ERC-20 `Transfer(address indexed from, address indexed to, uint256 value)`：`opCode = 3`，`data = abi.encode(value)`，`topic1 = from`，`topic2 = to`。
- `topic0 = keccak256("Transfer(address,address,uint256)") = 0xddf252ad1be2c89b69c2b068fc378daa952ba7f163c4a11628f55a4df523b3ef`
- 不匹配 / 低于阈值 → **`return`，不能 `revert`**（revert 照样收费）。
- `onlySystem` 防止别人伪造 `LogRecord` 调你的 `react()`。
- 回调 payload 第一个参数必须是 `address(0)` 占位，网络会替换成 Reactive 合约地址；目标链用 `onlyServiceProvider` + `onlyCallbackSender` 两道校验。
- 部署顺序：① 源链事件源 ② Lasna Reactive（订阅 + 充值）③ 目标链 Callback（带 ETH）④ `setRecipient` ⑤ 触发。
